# Production workflow
This adapts the reference CloneVoice + VideoExpress gate order for a consistent 3D narrator who speaks on camera. Do not assume an app offers any particular integration, control or exact lip sync.

## One-time setup
1. Keep approved concept and accepted reference sheets in assets/character/.
2. Pick a name only after creator approval.
3. Choose one authorized voice; keep a pronunciation guide. Never store voice samples or credentials here.
4. Check current image, animation/video, voice/TTS, audio and editing tools. Record model/version, limits, privacy, commercial terms, export settings and likely credit use in the episode ledger.
5. Run one small proof scene before batching.

## Gates
### 1. Brief, research and claims
Define topic, geography, dates, audience, runtime, ratio and tone in the episode brief. Research primary sources when practical plus reputable archives, museums, academic and specialist works. Record each claim, source URL, page/section, access date and status. Separate facts, interpretations and disputes. AI output is not evidence. Verify names, dates, numbers, quotations, maps and causal claims. Check period details against sources. Freeze the script before narration; any later factual edit updates script, audio, timings and ledger.

### 2. Voice and scene plan
Generate one complete performance using the same authorized voice. Listen through and correct pronunciation, pace, emphasis, clipping and facts. Split it into visual beats in scene-plan.csv, not automatically one sentence per row. Mark each beat on-camera, voiceover cutaway or silent; note real audio in/out time. Use final audio to drive lip sync when supported. Lock timings before rendering.

### 3. References and proof
Prepare model, expression, mouth/viseme and wardrobe sheets. Compare them to the approved image and identity locks. Select the episode's opening variant and plan any later changes. Render one short proof scene; check identity, readable mouth, eye/hat stability, sync, history details, framing and quality. Do not batch until it passes.

### 4. Create and review scenes
Generate stills using accepted character references and the chosen variant. Keep the identity block fixed; describe scene action separately. Add accurate labels and citations in the editor, not in generated text. Animate accepted stills only. Use final audio for dialogue when supported; cutaways carry continuous narration without a visible talking face. Record generation ID, model, prompt version, input reference, audio range, duration and status. Preview each result for identity, lip sync, movement, anatomy, text artifacts, history accuracy and privacy. Reject or repair failures. After interruption, inspect the media library and ledger before regenerating.

### 5. Assemble and export
Arrange accepted scenes against the master narration. Keep speech clear; use licensed music only if it leaves room for speech. Add titles, maps, labels, captions, dates and source credits in the editor. Review pacing, continuity, unsupported claims and identity drift. Export at chosen ratio/resolution and watch the export itself. Confirm duration, sound and end card. Save editable project and record export details.

## Historical and respectful visuals
Keep sequences within a clear date range and place. Mark modern borders as modern. Do not flatten a culture or make separate eras appear simultaneous. Name communities when supported by sources. For violence, forced migration, slavery, colonialism or persecution, name coercion and use sober visuals. Label reconstructions if viewers might mistake them for footage. Cite images, maps, music and footage as well as historical claims.

## Recovery and completion
After interruption, reread the ledger and inspect the tool's media library before generating again. Resume at the first unfinished beat. A queued generation is not accepted until previewed. Completion requires an approved script and claims, checked voice, frozen scene plan, accepted references, an accepted asset or explicit editorial replacement for every beat, assembled watched export, and saved project/source notes.
